# Mental-Health-DB-Project
University group project which explores a Kaggle dataset taken from a mental health survey.  This ML project utilizes four different algorithms to explore the factors that may cause depression based on that database.

- ANN
- Logistic Regression
- Random Forest
- CatBoost
